# Custom GUI Mod — Forge 1.12.2

Собственный игровой режим для Minecraft 1.12.2 с кастомным GUI, MongoDB и сетевым протоколом между клиентом и сервером. Проект вдохновлён архитектурой Cristalix.

## 🎯 О проекте

Проект демонстрирует полный цикл разработки игрового режима для Minecraft:
- **Кастомный GUI** (не сундук) — собственный экран с сеткой слотов, анимациями и tooltip.
- **Сетевой протокол** — двусторонняя связь клиент ↔ сервер через `SimpleNetworkWrapper`.
- **MongoDB** — сохранение баланса, карточек и мобов между сессиями.
- **Игровые механики** — покупка карточек, монеты, мобы с респавном, HP-бары.
- **Команды** — с Tab-автодополнением.

## ✨ Что реализовано

### Кастомный GUI
- Сетка 50 слотов (10 × 5).
- 3 слоя карточек: бронза, серебро, золото.
- Иконки предметов, названия, статы, уровень.
- Tooltip при наведении.
- Анимация полёта карточки из кнопки в слот.
- Кнопки количества: x1, x5, x10, x100, xВсе.
- Открытие по клавише `C` через KeyBinding.

### Сетевой протокол
- Канал `customgui:main`.
- Пакеты:
  - `PingPacket` (C → S) — действия (`buy_card`, `get_balance`, `load_cards`).
  - `PongPacket` (S → C) — баланс.
  - `CardPacket` (S → C) — карточка (слот, индекс, слой, animate).
- Разделение регистрации по сторонам.

### MongoDB
- База `cristalix_demo`.
- Коллекции:
  - `players` — `{ _id: uuid, balance, cards: [...] }`.
  - `custom_mobs` — `{ name, type, hp, money, x, y, z, enabled }`.
- Сохранение между сессиями.
- Синхронизация при входе и открытии GUI.

### Игровые механики
- Карточки — покупка за 100 монет.
- Монеты — за убийство мобов.
- Мобы — фиксированные, респавн 0.5с.
- HP-полоска над головой (цвет зависит от HP).
- Защита мобов от внешних источников (лава, огонь, TNT, молния).
- Без дропа.
- Урон от карточек — +1 урон за каждую карточку.

### Команды
- `/custommob create <имя> [деньги] [хп] [тип]` — создать моба.
- `/custommob setspawn <имя>` — точка спавна.
- `/custommob unspawn <имя>` — отключить спавн.
- `/custommob delete <имя>` — удалить моба.
- `/custommob list` — список мобов.
- `/customcards clear` — очистить карточки игрока.
- Tab-автодополнение для всех команд и имён мобов.

## 🧩 Архитектурные решения

### Разделение клиент/сервер
Один мод — работает и на клиенте, и на сервере.
Клиентская часть — `@SideOnly(Side.CLIENT)`.
Серверная часть — логика в `preInit` с проверкой `event.getSide() == Side.SERVER`.

### Кастомный рендер
HP-полоска рисуется через `RenderLivingEvent.Post`.
Сохранение состояния OpenGL через `pushAttrib()` / `popAttrib()` — ключевое для корректного рендера.
Проверка типа моба (`EntityZombie` / `EntitySkeleton`) — только наши мобы.
Проверка дистанции (> 32 блоков) — не рисуем далёких.

## 🔧 Проблемы и решения

### БАГ `BUKKIT` в enum `Side`
**Симптом**: краш `runClient` с `NullPointerException`.
**Решение**: обходной путь — Forge-сервер вместо Paper.

### Paper не видит Forge-пакеты
**Симптом**: `pong` не доходит до клиента.
**Решение**: Forge-сервер + `SimpleNetworkWrapper`.

### Аномалии рендера
**Симптом**: чужие мобы «летают» сквозь полоску HP.
**Решение**: `GlStateManager.pushAttrib()` / `popAttrib()`.

### Дубликаты пакетов
**Симптом**: 1 нажатие = 5 пакетов.
**Решение**: `TickEvent.ClientTickEvent` + флаг `wasPressed`.
