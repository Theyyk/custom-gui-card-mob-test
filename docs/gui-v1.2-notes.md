# GUI v1.2 — коллекция бустов

Видимая сетка содержит ровно 26 ячеек типов бустов, расположенных рядами 10 + 10 + 6. Сейчас определены 10 типов; остальные ячейки зарезервированы под будущие бусты. Новые типы не придумываем ради заполнения сетки.

Один тип занимает одну ячейку. Счётчик повторов в ячейке не показываем. Существующие серверные записи сохраняются; для текущего отображения используется лучший принадлежащий игроку ранг этого типа.

Будущая механика повторной покупки: игрок получает валюту, которой улучшает соответствующую стихию. Эта компенсация и улучшение стихии пока не реализованы.

В текущем layout-pass серверная механика покупки и хранения не меняется: лимит остаётся 50 записей на сборку, все ранее купленные руны сохраняются. 26 — число типов в интерфейсе, а не новый лимит серверных записей.
