# Earth rune icons

Place the eleven final PNGs in this directory (exact lowercase names):

- stone_hammer.png
- shadow_blade.png
- heart_of_forest.png
- forge_seal.png
- golem_heart.png
- moss_shard.png
- ancient_root.png
- obsidian_spike.png
- ancient_seed.png
- cracked_seal.png
- gold_nugget.png

Recommended: transparent 128 x 128 canvases, objects centered at a consistent scale
and with matching transparent margins. The renderer fits the full canvas, preserving
its aspect ratio, into a padded area above the separate type badge. Non-square PNGs
are supported. Missing/invalid files show a neutral framed placeholder. Reopen the
screen after reloading resources to refresh cached dimensions/missing-file results.
Repeated catalog positions share texture paths, but retain separate ownership/ranks.
No generated artwork is included. Other elements retain their existing item icons.
